# 積分影像演算法

## 摘要

本專題以 Python 實作資料結構與演算法中的積分影像（Integral Image）技術。程式透過動態規劃方法預計算二維矩陣的積分值，使得查詢任意矩形區域總和的時間複雜度降低至常數時間。同時提供圖形化使用者介面（GUI），讓使用者能輕鬆輸入矩陣、執行查詢並觀察演算法結果。

## 研究目標

1. 理解積分影像的核心概念與動態規劃原理
2. 實作積分影像的建立演算法，在 O(rows × cols) 時間內預計算所有可能的矩形區域總和
3. 實現高效率的矩形區域查詢函式，將查詢時間複雜度降低至 O(1)
4. 對比傳統方法（需要逐元素遍歷）與積分影像方法的時間複雜度差異
5. 設計易用的 GUI 界面供使用者互動與學習

## 系統設計

### 1. 積分影像建立 (`_build()`)

積分影像是二維矩陣的預計算結構，其中 `integral[r][c]` 儲存原始矩陣中從 `(0, 0)` 到 `(r-1, c-1)` 的矩形區域總和。

**建立公式：**
```
integral[r][c] = image[r-1][c-1] 
                  + integral[r-1][c] 
                  + integral[r][c-1] 
                  - integral[r-1][c-1]
```

**設計特點：**
- 使用多一列與多一欄的邊界（初始化為 0），方便處理邊界情況
- 採用動態規劃策略，自左上向右下依序計算
- 每個元素只需與相鄰元素進行常數次運算

### 2. 矩形區域查詢 (`get_sum()`)

利用預計算的積分影像，在常數時間內查詢任意矩形區域的總和。

**查詢公式：**
```
sum(top, left, bottom, right) 
  = integral[r2][c2] 
    - integral[r1-1][c2] 
    - integral[r2][c1-1] 
    + integral[r1-1][c1-1]
```

其中 `(r1, c1)` 為查詢矩形的起始座標，`(r2, c2)` 為結束座標（均為 1-based）。

**四個矩形的加減法原理：**
- `integral[r2][c2]`：包含整個查詢區域的矩形
- 減去 `integral[r1-1][c2]`：排除上方多餘部分
- 減去 `integral[r2][c1-1]`：排除左方多餘部分
- 加上 `integral[r1-1][c1-1]`：補回重複扣除的左上角區域

### 3. 座標驗證

程式進行邊界檢查與座標合法性驗證：
- 確保座標在有效範圍內 `[0, rows-1] × [0, cols-1]`
- 確保起始座標不大於結束座標

### 4. 圖形化使用者界面 (GUI)

使用 Tkinter 框架提供三個主要功能區：
- **矩陣輸入**：支援逗號或空格分隔，多行輸入
- **矩形查詢**：輸入四個座標參數進行查詢
- **結果顯示**：同時展示原始矩陣、積分影像與查詢結果

## 操作流程

1. 執行程式，啟動 GUI 視窗
2. 在「矩陣輸入」區域輸入或修改矩陣（預設提供 5×5 範例矩陣）
3. 點擊「載入矩陣」按鈕，程式計算積分影像
4. 在「矩形查詢」區域設定四個座標參數（top, left, bottom, right）
5. 點擊「查詢矩形和」按鈕，程式在 O(1) 時間內回傳查詢結果
6. 在「結果顯示」區域檢視原始矩陣、積分影像與查詢結果

## 時間複雜度分析

令：
- `rows`、`cols` = 矩陣行數與列數
- `n` = 矩陣元素總數 = `rows × cols`

### 主要步驟的複雜度

| 步驟 | 時間複雜度 | 空間複雜度 |
|------|----------|----------|
| 積分影像建立 | O(rows × cols) | O(rows × cols) |
| 矩形查詢 | O(1) | O(1) |
| GUI 渲染 | O(rows × cols) | O(rows × cols) |

**整體時間複雜度**：
- 初期化：O(rows × cols)（一次性）
- 單次查詢：O(1)（常數時間）
- 多次查詢：O(k)（k 為查詢次數）

**對比傳統方法：**
- 傳統直接求和：每次查詢需 O((bottom-top+1) × (right-left+1)) 時間
- 積分影像方法：每次查詢恆為 O(1) 時間
- 當查詢次數 ≥ n 時，積分影像方法優勢明顯

## 注意事項

1. **座標系統**：採用 0-based 索引，即第一個元素位置為 (0, 0)

2. **矩陣輸入格式**：
   - 逗號或空格分隔均可
   - 支援多種數值類型（整數、浮點數）
   - 務必確保每列元素個數相同

3. **座標邊界檢查**：
   - 起始座標必須 ≤ 結束座標
   - 所有座標必須在 [0, rows-1] × [0, cols-1] 範圍內

4. **效能特性**：
   - 預計算時間隨矩陣大小線性增長
   - 查詢時間恆定為常數時間，與矩陣大小無關
   - 適合需要頻繁查詢的應用場景

5. **GUI 字體**：程式預設使用「新細明體」，若系統無此字體將自動使用預設字體

6. **錯誤處理**：程式包含完整的錯誤檢查與使用者提示

## 延伸應用

1. **影像處理**：用於快速計算影像區域特徵（如平均亮度、方差等）

3. **機器學習**：Haar 特徵計算（Viola-Jones 物體檢測演算法的基礎）
4. **統計分析**：快速計算任意矩形區域的統計量

本實作透過積分影像演算法示範如何利用預計算與動態規劃技術將查詢時間複雜度從 O(area) 優化至 O(1)。該演算法廣泛應用於影像處理、電腦視覺與範圍查詢等領域，是資料結構與演算法課程中重要的最佳化技巧。透過 GUI 界面的互動設計，使學生能直觀理解動態規劃的威力與實務應用。
